# AI Lab — AI Portfolio

A personal AI portfolio website showcasing machine learning projects, skills, and experiments.

## Features

- **Animated hero** with a live neural-network canvas background and a typing effect
- **About** section with animated counters and a code snippet card
- **Skills** grid covering ML, Deep Learning, NLP/LLMs, Computer Vision, Data & MLOps
- **Projects** gallery with category filtering (NLP, Computer Vision, ML, Generative AI)
- **Contact** form with client-side validation
- Fully responsive, mobile-friendly design
- Smooth scroll-reveal animations throughout

## Structure

```
AI_Lab/
├── index.html   # Main portfolio page
├── styles.css   # All styles (dark theme, responsive)
└── script.js    # Interactivity (canvas, typing, filters, form)
```

## Usage

Open `index.html` in any modern browser — no build step required.
